# Track Epic

Follow the workflow in `docs/workflows/epic-issues.md` to create a GitHub epic issue that groups a coherent phase of work within a parent feature.

Read that file and follow it exactly. It covers what to confirm from session context, how to structure the issue body, runtime classification, CSL coordination requirements, and the quality checks to apply before creating.
